# Gains Graph
Web app dashhboard that charts lifts over time to visualize progress.

1. I log each lift each day on a Google Sheets and periodically log body measurements.
2. The app turns each lift into a graph of estimated 1-rep max over time, using the Epley equation.

## Why
1. I want progress charts to visually see my lifting improvements over time.
2. My phone app that I already use to log lifts does not chart lifts in the way I want it to. It includes too much information that makes it hard to keep track of how I'm doing.
3. Doubles as a portfolio project for DevOps/SDET/QA roles.

## Status
In progress: level 0 - setup

## Privacy
Body stats stay local, never committed to Git.
